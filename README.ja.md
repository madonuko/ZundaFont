# ずんだフォント

ボイロや界隈曲に関する絵文字フォント。

## 利用規約

ずんだフォントを使う際、**[`TERMS.md`](/TERMS.md)に記載された利用規約を徹底的に理解し、遵守することが義務付けられています。**

## ライセンス

フォントのライセンスは[`OFL-1.1-RFN`](/OFL.txt)。[ウィキペディアの記事](https://ja.wikipedia.org/wiki/SIL_Open_Font_License)をご参考ください。

コードのライセンスは[`MIT`](/MIT.txt)です。

## 作り方

- [psvg](https://github.com/kagof/pixel-perfect-svg)
- [nanoemoji](https://github.com/googlefonts/nanoemoji)
以上２つのツールをインストールし、`just map-all build`を実行。
